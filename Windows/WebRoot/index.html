1:1 JavaScript-Code

Die gleichen Aufrufe kannst du direkt in deiner eigenen Seite verwenden.

JavaScript 
await window.customBrowser.minimize();
await window.customBrowser.restore();
await window.customBrowser.maximize();
await window.customBrowser.toggleKiosk();
await window.customBrowser.close();

const result = await window.customBrowser.getState();
console.log(result.state);

// Falls control_password gesetzt ist:
await window.customBrowser.toggleKiosk("secret");

CLI-Beispiele

Konfigurationen können beim Start überschrieben werden.

Terminal 
CustomBrowser.exe --show_addressbar=true --allow_tabs=true
CustomBrowser.exe --show_adressbar=true --tabs=true

Hinweis: --show_adressbar ist als Alias enthalten, falls die ältere Schreibweise verwendet wird.

Config-Keys

Alle wichtigen Optionen aus der ini.json auf einen Blick.

Key Bedeutung
urlStart-URL oder HTML-Datei relativ zur ini.json.
portLokaler HTTP-Port. 0 öffnet lokale Dateien direkt.
title_nameFenstertitel links oben.
icon_pathICO-Datei links oben, relativ zur ini.json.
enable_minimizeMinimize über UI und JS aktivieren.
enable_maximizeMaximize/Restore über UI und JS aktivieren.
enable_closeClose über UI, Alt+F4 und JS aktivieren.
enable_move_windowFenster per Drag auf Titelleiste verschiebbar.
enable_kiosk_mode_toggleKiosk-Button ⛶ und JS-Toggle aktivieren.
start_window_sizeauto, maximize, minimize, Breite,Höhe oder BreitexHöhe.
start_in_kioskDirekt im Kioskmodus starten.
control_passwordLeer = kein Passwort. Sonst für minimize, restore, maximize, toggleKiosk und close nötig.
dev_toolsWebView2 DevTools aktivieren/deaktivieren.
extensions_enabledWebView2 Browser Extensions aktivieren/deaktivieren.
title_bar_height_pxHöhe der Titelleiste.
title_bar_button_height_pxHöhe der Titelleisten-Buttons.
title_bar_button_width_ratioButton-Breite = Button-Höhe × Ratio.
title_bar_button_gap_pxAbstand zwischen den Buttons.
show_addressbarURL-Leiste anzeigen. CLI-Alias: --show_adressbar, --addressbar.
allow_tabsNeue Tabs über window.open oder target="_blank" erlauben. Wenn false, wird im aktuellen Tab navigiert.
